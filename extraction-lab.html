EXPERIMENT 0.8 / MACHINE CANDIDATES

SEC clause extraction lab

Extract candidate headings, categories, and cross-references from pasted SEC exhibit text or HTML. This tool runs entirely in the browser. It does not fetch SEC filings or send pasted content to a server.

Research status: All extracted records are machine_candidate_unreviewed. A keyword match is not a validated clause finding. Verify with the SEC exhibit before adopting any classification.


Workflow and limitations

Download the SEC exhibit using your browser and paste its content here, or process a saved local HTML file with the CLI. The extractor identifies numbered headings using simple heuristics: table-of-contents duplication, omitted headings, and inaccurate section boundaries are possible. A separate review step must establish source identity, document completeness and verified clause pinpoints.
